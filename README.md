# Le hangar à bananes

Blog du chantier, construit avec [Hugo](https://gohugo.io) et le thème PaperMod.

- Écrire un article : créer `content/etapes/NN-titre/index.md` avec ses photos dans le même dossier.
- Prévisualiser : `hugo server`, puis ouvrir http://localhost:1313
- Publier : envoyer sur la branche `main` ; GitHub Pages reconstruit le site tout seul.
